# Personal skills

## Install

Select your agents when prompted.

```bash
npx skills add Zhunio/skills --skill software-engineering i-have-adhd email browser-use message -g
npx skills add Zhunio/skills --skill NetSuite --rename netsuite -g
```

## Skills

| Skill | What it does |
|---|---|
| software-engineering | Standards for readable code, module design and testing. |
| i-have-adhd | Concise, action-focused responses with visible progress. |
| email | Check, summarize, draft and send emails with approval. |
| netsuite | Search, report on and update NetSuite records with approval. |
| browser-use | Browse signed-in websites through dedicated Chrome profiles. |
| message | Check, summarize and reply to messages through Beeper. |
